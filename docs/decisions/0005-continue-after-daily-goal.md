# Decision 0005: 하루 목표 이후에도 이어서 학습하기

상태: accepted  
날짜: 2026-09-09

## 결정

일일 목표는 학습을 시작하기 위한 기본 배치 크기이지, 그날 학습을 막는 상한선으로 사용하지 않는다. 현재 배치의 모든 항목을 완료한 뒤 다시 학습을 시작하면, 사용자 트랙에 맞는 새 단어를 목표 개수만큼 추가해 이어서 학습한다.

기존 배치의 순서와 완료 기록은 유지한다. 추가 배치는 새 개인 단어를 먼저 사용하고, 빈자리는 아직 사용자 단어장에 가져오지 않은 카탈로그 단어로 채운다. 같은 날 같은 사용자에게 이미 가져온 카탈로그 단어는 다시 추가하지 않는다.

## 이유

오늘의 목표를 달성했다는 사실과 더 공부할 수 없다는 상태는 다르다. 목표를 강제 상한으로 처리하면 사용자가 복습을 더 이어가고 싶을 때 빈 화면으로 끝나며, 대시보드의 “남은 단어도 이어갈 수 있습니다” 안내와도 모순된다.

## 경계

- 하루 계획의 위치는 기존 제한을 지키기 위해 최대 200개까지만 추가한다.
- 카탈로그가 소진되거나 활성 트랙에 더 가져올 단어가 없을 때만 완료 화면을 보여준다.
- 모든 단어 선택과 카탈로그 import는 기존 `start_daily_session` RPC의 사용자 잠금과 RLS 경계를 따른다.
