# Decision 0006: 사용자별 적응형 학습 수준

상태: accepted
날짜: 2026-09-09

## 결정

WordLoop는 공유 카드의 고정 난이도(`L1`–`L7`)와 별개로 사용자별 `ability_score`를 유지한다. 점수는 학습자의 최근 수행을 바탕으로 다음 새 단어의 난이도를 조절하는 내부 학습 파라미터이며, TOEIC·DET 점수 환산값이 아니다.

세 가지 상태를 분리한다.

- `vocabulary_catalog.difficulty`: 편집자가 부여한 카드 난이도
- `user_ability`: 사용자 전체의 적응형 수준과 평가 신뢰도
- `review_state`: 개별 단어의 기억 단계와 다음 복습 시각

## 점수 갱신

초기 점수는 500점, 초기 수준은 L4다. 점수는 0–1000 범위로 유지하고 일정 구간을 L1–L7로 표시한다. 현재 문제의 카드 난이도와 사용자 수준을 비교해 기대 정답률을 계산한 뒤, 실제 응답과의 차이를 반영한다. 현재보다 어려운 카드를 맞히면 더 크게 올라가고, 쉬운 카드를 틀리면 더 크게 내려간다.

응답별 증거 가중치는 다음과 같다.

| 응답 | 가중치 |
|---|---:|
| 직접 입력 · 무힌트 | 1.00 |
| 직접 입력 · 힌트 사용 | 0.35 |
| 객관식 | 0.45 |
| 정답 보기 후 자기평가 | 0 |

`sample_count`는 점수에 반영된 typed/choice 응답만 세고, `confidence`는 20회까지 선형으로 높인다. 자기평가는 복습 일정에는 반영하지만 능력치의 증거로 세지 않는다.

## 문제 선택

새로 추가하는 카드에는 현재 수준 카드를 약 60%, 한 단계 낮은 카드를 약 25%, 한 단계 높은 도전 카드를 약 15% 배정한다. 해당 구간의 카드가 부족하면 전체 활성 카드에서 부족분을 채운다. 기한이 된 복습 단어와 이미 열린 오늘의 계획 순서는 이 규칙보다 우선한다.

오늘의 첫 계획은 생성 시점의 능력치를 고정하고, 사용자가 오늘의 기본 배치를 모두 끝낸 뒤 추가 학습을 요청하면 그때의 최신 능력치로 보너스 배치를 만든다. 한 번의 응답으로 공유 카드를 재분류하지 않는다.

## 데이터·안전 경계

- `submit_review` 안의 review event insert trigger가 정답 판정 결과를 받아 `user_ability`를 갱신한다.
- `review_events`에는 능력치 변경 전·후·증분·수준 snapshot을 함께 저장한다.
- 사용자별 advisory lock과 기존 응답 ID 멱등성으로 재시도 시 능력치가 중복 상승·하락하지 않는다.
- `user_ability`는 사용자 본인만 읽을 수 있고, 쓰기는 보안 정의 함수와 trigger만 수행한다.
- 능력치가 낮아져도 개별 단어의 `review_state`는 별도로 유지한다. 한 단어를 잊은 것이 전체 능력치로 과도하게 전파되지 않도록 응답 유형별 가중치를 둔다.

## 운영·검증

현재 수준은 대시보드에 `WordLoop 수준`으로 표시하고, 신뢰도와 근거 횟수를 함께 보여준다. 공식 시험 점수나 합격 가능성으로 표시하지 않는다. 테스트는 초기값, typed/choice/self 가중치, 멱등성, 사용자 간 접근 차단, 현재 수준 주변의 카드 선택을 검증한다.
